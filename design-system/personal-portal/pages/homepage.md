## 构图与内容

连续浅灰绿画布贯穿首屏、实习、开源、系统设计与博客；教育带与联系区使用同一浅层表面。深色仅用于首屏右侧本体与规则执行面板，配合细边框和有限阴影。

主标题“从业务语义，到可靠执行。”。左侧先展示姓名、校招方向和京东/Semantica 工作重点，主操作直接进入京东实习和开源贡献。GitHub 保留可见入口。三段真实实习保持原顺序和事实，京东标题以强调色突出。

页面与导航顺序：实习 → 开源 → 系统 → 博客 → 联系。Semantica 标志使用原始完整图像并放大至可读尺寸。开源项目介绍后展示三栏能力图，再进入个人贡献与 PR 证据。

最大内容宽度 1280px，桌面边距至少 48px；章节留白 96px。中文使用系统字体，英文展示使用本地 Space Grotesk，代码与事件标注使用等宽字体。

## 交互与能力图

回放以虚构供应商资质审核串起 Agent 任务 → 本体映射 → 规则编译 → 执行校验 → 事务写回。读者可播放、暂停、选择阶段和拖动进度。

- 正常授权到 100%，显示示例风险标记写回。
- 只读权限停在 75%，禁用写回步骤，说明没有执行事务。
- 行数异常到 100%，显示整个事务回滚及 0 条变更生效，终点改为警示状态。

切换场景清空前一个结果；离屏、隐藏与卸载时停止计时。初始静态，水合前禁用控件，无 JavaScript 保留说明。reduced-motion 禁用路径和过渡动画；原生 range 支持方向键、Home、End。百分比仅代表示例步骤，不发送真实请求。

Semantica 图提供自包含 1440×820 SVG 和 2880×1640 PNG。三栏为数据源、语义与上下文层、Agent 与应用，底栏独立列出个人贡献。正文明确区分整体项目能力与个人工作；有全尺寸图和 README 来源入口。图像预先加载并固定宽高，避免初次完整阅读/截图缺图。
