# 首页：工程作品展

日期：2026-09-29。用户选择方案 1，并加入方案 3 的一个代表性交互。旧版 `53cc651` 已保存到 GitHub 的 `design/ui-ux-homepage`；新版位于 `design/engineering-showcase`。

## 构图与视觉

- 石墨黑首屏与联系区，浅灰蓝阅读区。左侧姓名、职业方向和主操作；右侧可操作的 Agent 任务回放。
- 经历索引横排展示三家公司；教育与联系方式在独立浅色信息带展示。1280×800 首屏保留姓名与主操作，教育可向下阅读。
- 三段实习各配一张标明「工程示意」的 SVG：本体与规则、机器人数据流回放、检索与规划。正文保留工作、贡献、成果及展开的工程细节。
- 系统案例保持原交互；开源区域突出 Maintainer / Collaborator 与已有事实快照；技术博客使用宽松的单列条目。
- 最大内容宽度 1280px，桌面边距至少 48px。章节留白 96px；大标题、细分隔线与少量浅色表面组织层级。

## 代表性交互

回放显示「接收任务 → 检索上下文 → 生成建议 → 权限校验 → 提交结果」，读者可播放、暂停、拖动进度或选择阶段。只读权限停在 75% 并说明阻断原因；正常授权到 100%。百分比仅为示例步骤进度，不代表真实耗时，不发送外部请求。

初始静态显示完整场景，水合前控件禁用；无 JavaScript 时说明静态示例。离屏、隐藏标签页和卸载时停止计时。reduced-motion 禁用路径与过渡动画，保留用户主动操作。键盘可使用原生按钮及 range 的方向键、Home、End。200% 字号时阶段标签自动换行。

## 范围与校验

仅验收 1280、1440、1920px 桌面；用户明确暂缓手机适配。窄屏首页回归用例保留并标注暂缓，不宣称移动端完成。博客全部尺寸、内容和 CSS 保持独立，客户端导航后也检查正文排版。

首页样式限定于 `.engineering-showcase` 或组件 CSS Modules，不引入全站深色主题、远程字体、WebGL 或动画依赖。保留所有真实实习指标、PR 快照日期与来源；概念图不冒充真实业务截图。
