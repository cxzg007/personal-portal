## Skill 使用与校准

来源：`nextlevelbuilder/ui-ux-pro-max-skill@09170eec67eefd46a7ae85de61b40c194020f997`，安装于 JoyCode 全局 skills。

- `developer portfolio minimal professional --design-system` 误匹配为文档站与深色开发工具，不采用。
- 按技能要求缩小为 `personal portfolio --design-system`，命中作品集的蓝色强调和章节叙事；保留完整 DOM 阅读顺序与低动效建议。
- 该结果中的 Brutalism、Caveat/Quicksand、章节递进色与滚动叙事不适合本项目，不能直接作为实施规范。
- `minimalism light --domain style` 命中 `minimalism-and-swiss-style`：采用网格、留白、无衬线层级、少阴影及轻交互。
- `text reflow zoom --domain ux`：内容高度自然增长，长文本安全换行，标签组允许换行。
- `heading hierarchy --domain ux`：标题顺序保持 h1–h5，不用装饰编号表达不存在的顺序。
- `responsive images server components --stack nextjs`：静态内容保留 Server Components，图片使用既有 Next Image。框架实现以本项目安装包内 Next 16.3.1 文档为准。

本文件是以上建议经过项目校准后的实施规范；原始生成结果留在忽略入库的 `.superpowers/ui-ux-pro-max-source.md`。

中文正文使用系统无衬线；Noto Serif SC 600 用于主页栏目、大学名称与文章标题；英文副标、编号和时间使用既有等宽字体。正文16px、辅助说明13–14px、英文标记与图内元信息11–12px、主要章节标题32–36px、技术ID桌面88–96px、手机52–64px。小字只承载辅助信息，保持可读对比度和自然换行。保留完整中文信息与所有量化指标的适用条件。

栏目标题配英文副标，中文保持主层级：ENGINEERING EXPERIENCE / SELECTED SYSTEMS / OPEN SOURCE / WRITING & NOTES / LET’S BUILD TOGETHER。英文不并入章节的可访问名称。姓名中英文字号与斜线对比度分层，避免与技术 ID 争抢视觉重点。

页面内容最大宽度1120px；桌面章节上下留白72px，手机48px；普通表面12px圆角，按钮8px。只为导航等浮层设置轻阴影。聚焦轮廓至少2px；主要交互区域至少44px高；颜色变化约180ms，reduced-motion时禁用过渡。

标题与英文技术词允许安全换行。系统节点区域宽度不超过18rem时，按原DOM顺序显示自然高度的节点列表，保留节点解释交互，隐藏装饰连线；容器查询同时支持窄屏和200%文字放大。折叠区使用加号/减号表达状态，避免旋转图标越过边界。

贡献图作为主要阅读入口：三个方向、六个节点合并主题说明和八个关键 PR，其他十一项默认折叠。每个 PR 在开源区只出现一次，后续未映射贡献自动进入补充记录。图中区分已合并与进行中，源码固定到核验提交。窄屏时补充记录将编号与标题分行，放大文字时不能被固定列挤压；不以裁剪隐藏内容来消除溢出。

## 实施边界

实习索引复用内容JSON与稳定锚点，首屏核心身份、教育、CTA应在1280×720可见。删除首屏语义图的消费与动效驱动，保留章节导航与既有系统案例交互。保留实习扩写、18个已合并PR、1个开放PR及维护者身份和事实快照，不改事实数据。

主页作用域承载新视觉；博客页面保持本轮基线，跨路由检查不得引入样式泄漏。主目录未完成的联系后端不进入本工作树。当前迭代沿用用户已授权的提交、推送与正式站部署流程。
