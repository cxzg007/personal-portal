# 潜空间内容层导航设计

现有场景支持提问检索，却无法在远景辨认五个内容层。访客需要能从空间直接进入身份、实习、系统、开源、博客。

- 在远景和中景，把五个可聚焦的 HTML 标签投影到对应的 L3–L7 附近，层号与名称读 `DOMAIN_LAYER` 和 `DOMAIN_LABEL`。标签跟随镜头位置；终端、载入和检索飞行时收起，避免压住内容或抢交互。
- 悬停与键盘聚焦标签时，只强调相应层并降低其他层的节点亮度。离开标签或失焦时恢复；飞行期间维持现有检索高亮。标签使用可见焦点、完整点击区域，减少动态效果时保持状态反馈。
- 点击标签直接请求终端机位，并经已有同源 iframe 消息桥发送 `open-domain`。内层按域打开相应页签；身份、实习、系统各自有独立内容页，开源和博客保留，提问与索引仍可访问。终端页签沿用同一份服务端检索索引。
- 容错：校验消息域名；iframe 尚未就绪时保留待发送域，收到 `ready` 后送达；在前向飞行阶段禁用标签，不中断答案往返。窗口缩小时继续现有静帧降级。首页依旧不加载场景代码。
- 验证：消息桥非法域拒收；浏览器检查标签随镜头、鼠标与键盘选中、内容页签切换、提问与全文链接回归，运行单测、类型检查、lint、生产构建。

不引入新依赖、不改内容正本、不扩大到自由漫游或移动端三维模式。
