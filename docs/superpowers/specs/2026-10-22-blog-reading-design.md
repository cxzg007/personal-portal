# 技术博客阅读版式

用户已选择：Josh Comeau 的文章结构、Anthony Fu 的中文阅读感，以及现有手绘图。目标是改善所有博客详情页的长文阅读，保留内容与编号书面标题。

## 视觉

白色正文 #ffffff、浅蓝标题底 #f4f7fb、墨蓝文字 #172b45、辅助文字 #53657d、强调蓝 #2458a6、分隔线 #d6dfec。标题使用已有 Noto Serif SC 600，正文使用系统中文无衬线字体，代码保留等宽字体，不增加字体请求。

桌面内容容器最大 66rem；正文最大 45rem（720px），右侧目录与正文间距 4rem。标题区横跨内容宽度，以浅蓝背景区分标题与正文，标题内主题和具体题目分层。正文 18px、1.85 行高；小屏保留 17px。章节加大上间距，图注采用左侧细线与更清晰字号。插图保留白底、原图链接与替代文字，宽屏图形向左右各扩展 24px，窄屏收回正文宽度。

## 交互

沿用原生锚点与 details。启用 JavaScript 后，右侧目录跟踪阅读位置，通过蓝色文字、背景和 aria-current=location 指示当前标题。滚动监听通过 requestAnimationFrame 合并，图片/字体改变排版后重新定位；组件卸载时清理监听。无 JavaScript 时目录仍可展开和跳转。只改变阅读辅助行为，不引入滚动劫持或入场动画。

## 验证

检查最新 Agent 配图文章、包含代码的本体文章、带表格的高并发文章。覆盖目录点击、滚动回读、直接锚点访问、长目录自身滚动、图片加载、无脚本目录、200% 字号，以及桌面/平板/手机的溢出和可访问性。保留首页样式与内容。完成后沿用既有 GitHub 分支及 Vercel 正式站发布流程。
