## 视觉规范

- 首屏背景 `#101317`，抬升面 `#191f28`，深色文字 `#f1f5fa`，次级 `#a7b3c5`。
- 交互冰蓝 `#8ab4ff`，内容强调蓝 `#2458a6`；浅色背景 `#f5f7fa`，正文 `#19283b`。
- 中文标题采用系统无衬线，桌面 56–80px；技术 ID 使用本地等宽字体，大型英文标记采用本地自托管 Space Grotesk（如获取失败则用系统无衬线）；正文系统无衬线 16px，博客延续既有独立设计。
- 主要容器最大 1280px；首屏左右约 40/60；阅读章节 88–112px 留白。重点验证 1280、1440、1920px 桌面。
- 非满屏统一卡片：首屏仪器面板、实习大幅叙事、开源贡献矩阵、博客纯文字条目形成节奏。
- 不引入滚动劫持。核心内容不依赖入场动画显现。保留键盘焦点、reduced-motion、无 JS 核心阅读。

## 代表性交互

`AgentReplay` 是局部客户端组件；模拟一次“审查变更并提交审查结果”的执行轨迹。明确标注“示例数据 · 交互演示”，不冒充线上实习系统、真实延迟或真实 API 调用。

- 原生范围输入调节时间点；播放、暂停与重播；可直接选择阶段。
- 五个阶段：接收任务、检索上下文、生成建议、权限校验、提交结果。
- 两个场景：具备写入权限时完成；只读权限时停在校验并显示拦截原因，后续提交不发生。
- 场景切换重置播放，拖动暂停，播放在末尾停止；组件卸载、页面隐藏、离开视口停止计时。
- 初始静止，用户主动播放；低动效时取消装饰动效并保留所有功能。初始 DOM 与客户端一致。
- SVG / CSS 实现空间节点、连线和数据流，不增加 3D 运行库；文字说明和控件承载真实语义，装饰图形 aria-hidden。
- 无 JS 时保留静态示例与说明，演示控件不制造可以操作的错觉。
