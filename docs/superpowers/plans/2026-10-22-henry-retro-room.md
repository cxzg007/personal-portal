# Henry Heffernan 复刻模块实施方案

**目标：** 在个人主页增加「交互实验室」，进入本地托管的 Henry Heffernan 复古 3D 房间及桌面体验。

**方案：** 直接复用作者的 portfolio-website（MIT）与 portfolio-inner-site（仓库未附许可证） 源码、模型和材质。在独立静态资源路径构建旧版 React / Three.js 应用，用 Next.js 的 `/playground` 页面承载，主页仅渲染预览卡片。与纯 CSS 仿制相比可保留镜头、着色器、声音、窗口操作；与远程嵌入相比可本地构建、替换内容、独立运行。

**视觉：** 保留原版灰色房间、米白 CRT、黑色桌面与蓝绿色 Windows 桌面。主页入口沿用本站排版，插在技术博客与联系之间，增加实验室导航。独立页面提供返回主页和 3D / 2D 切换；减少动画默认进入 2D。按用户补充要求，仅以桌面端复刻为验收范围，不适配手机桌面及游戏。

**边界：** 保留房间 MIT 许可、桌面来源声明和固定源码提交；原有未提交工作不覆盖。替换原作者个人内容为本站内容，保留设计署名。关闭第三方统计与邮件接口，不自动调用外部服务。资源从本站路径加载。

- `pnpm build:playground`：隔离依赖重新安装及两份静态应用构建通过。
- `pnpm lint`、`pnpm typecheck`、`pnpm build`：通过。
- `pnpm test`：36 个文件、286 项测试通过。
- 桌面浏览器回归：home / accessibility / reduced-motion / playground / visual，38 项通过、1 项设备范围跳过。
- 手动检查：启动、镜头推进、窗口拖动、最小化与恢复、Doom 运行；桌面预览与截图已核对。
- 本次只更新桌面视觉基线；手机实验桌面与游戏适配按用户要求不在交付范围内。
