# 贡献区整合与主页字排优化

用户要求解决贡献列表与落点图重复，并优化字体、英文标注与小字细节。直接基于已上线的 `b5702a4` 执行，分支 `design/contribution-editorial`。

## 设计

图作为主要贡献信息入口，六个节点汇集原来的主题说明与代表 PR。将 #1096 纳入规则推理、#1544 纳入真值维护；图展示 7 个已合并和 1 个进行中 PR，剩余 11 个已合并 PR 折叠展示。移除重复主题卡和已在图内展示的正在推进记录。所有贡献只出现一次；新增未映射 PR 自动落入补充记录。项目身份、官方图标、荣誉和总计保持可见。

字体沿用现有资源：Noto Serif SC 600 用于栏目标题，系统无衬线用于正文，等宽字体用于英文副标、日期和 PR 编号。英文栏目名用作导航辅助（Experience / Systems / Open source / Writing / Contact），保持中文主要信息。微调正文行距、字重、元信息对比度，移除过小的图内标签和源码长路径产生的阅读噪音。

浅蓝底、深蓝文字、白色表面沿用现有 token。无额外字体下载或运行时依赖；不改博客正文与实习事实。
